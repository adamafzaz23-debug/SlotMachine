# 🎰 SlotMachine

A simple terminal-based slot machine game built with Python.  
The player spins the reels and tries to match symbols to win.

## 📌 About
This is a beginner Python project that demonstrates:
- Random number generation
- Basic game logic
- Conditionals and loops
- User input handling

## 🎮 How it works
- The player starts the game
- The slot machine randomly selects symbols
- If all symbols match, the player wins
- Otherwise, the player loses
